# BloomBeyondTheNight-
Bloom Beyond the Night is an interactive animation made using the Processing Python mode. Press the space bar to create a meteor into a flower, gradually turning night into day. Meteors represent emotions, while flowers symbolize hope and the promise of a better tomorrow. 

File Navigation
README.md — Contains the project description and instructions.
BloomBeyondTheNight.pyde — Contains the source code for the interactive animation.

How to Run
1. Install Processing with Python Mode.
2. Download the project files from this repository.
3. Open the .pyde file in Processing Python Mode.
4. Click the Run button to start the animation.
5. Press the space bar to generate shooting stars.
6. Continue generating flowers to gradually change the sky from night to day.
